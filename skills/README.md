# Better Sol Agent Skill

A single, self-contained Agent Skill for building blockchain programs on Solana with Better Sol. Covers the full journey from concept to production.

## What it covers

**Build** — Scaffold, write programs, clients, tests, deploy. Better Sol SDK API, program patterns, account modeling, CPIs, debugging, Anchor interop, dApp architecture, advanced Solana runtime.

**Learn** — Solana fundamentals, web3 concepts, consensus mechanisms, execution environments, cross-chain architecture, structured learning tracks and exercises.

**Domain** — Architecture for specific domains: DeFi (AMMs, lending, staking, perps, yield), tokens, NFTs, DAOs, oracles, cross-chain bridges, stablecoins, RWA tokenization, data pipelines, mobile dApps, sybil resistance.

**Secure** — Security audit, attack catalog, cross-chain security patterns, economic security, game theory, threat modeling, severity calibration, test plans.

**Design** — Brand, transaction UX, multi-chain UI, dApp state management, accessibility, number formatting, motion and animation, pitch and video craft.

**Launch** — Strategy, validation, tokenomics, go-to-market, community building, pitch decks, grants, marketing, product review, DeFi market research.

better-sol/

## Standard compliance

- `name` matches folder name.
- Description is trigger-oriented.
- Detailed material lives in `references/` for progressive disclosure.
- File references are relative to the skill root.
- `SKILL.md` stays under 500 lines.
