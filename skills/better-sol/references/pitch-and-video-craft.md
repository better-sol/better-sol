# Pitch and Video Visual Craft

Use this reference when designing pitch deck visuals, demo video frames, product screenshots, end cards, or launch visuals.

## Frame principles

- One focal point per frame.
- The product should be readable without zooming.
- Captions should add context, not repeat the obvious.
- Use callouts for transaction signatures, account state, wallet actions, and before/after states.
- Proof beats decoration.

## Product screenshot treatment

Use a device frame or browser frame when it helps context. Avoid frames that shrink the product until text is unreadable.

Good screenshot frame includes:

- title bar or device context
- clean background
- one highlighted area
- short caption
- optional transaction/proof badge

## Pitch slide visual hierarchy

- Title states the takeaway.
- Main visual proves the takeaway.
- One supporting sentence adds detail.
- Footer can hold program address, link, or source.

## Demo end card

Include:

- product name
- one-line value proposition
- URL or repo
- QR code if appropriate
- devnet/mainnet/program proof if relevant
- contact or CTA

## Crypto-specific proof visuals

- transaction signature with explorer label
- account before/after values
- program ID
- test passing summary
- wallet signing state
- protocol integration logos only when actually used

## Avoid

- tiny full-page screenshots
- generic blockchain cubes
- random token logos
- unverified partner logos
- charts with no axis or source
- “AI x crypto” visuals that do not explain the product
