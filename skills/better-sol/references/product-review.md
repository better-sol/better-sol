# Product Review and Roast

## Review dimensions

Grade A–F:

- clarity: can a new user explain it after 10 seconds?
- activation: can the user reach first value quickly?
- trust: are financial/security consequences clear?
- transaction UX: are signing and confirmation states safe?
- differentiation: why this instead of alternatives?
- retention: why come back?
- proof: does it demonstrably work?
- craft: does it feel intentional rather than generic?

## Harsh critique prompts

- What would make a user bounce immediately?
- What sounds like a feature but is not a benefit?
- What looks like generic crypto wallpaper?
- What would a judge or investor not believe?
- What breaks in a live demo?
- What is the smallest fix that changes the outcome?

## Prioritization

Fix in this order:

1. cannot understand product
2. cannot complete core action
3. cannot trust transaction
4. demo breaks
5. differentiation unclear
6. retention loop absent
7. visual polish
