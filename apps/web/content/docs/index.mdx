Better Sol is a pure TypeScript library with no framework opinions. It works with Next.js, TanStack Start, Remix, Astro, Express, Hono, React Native, Bun, Deno, or any other JavaScript runtime. The program definition is a plain TypeScript file. Import it, pass it to `betterSol()`, and you get a fully typed client. No code generation, no build plugins, no framework coupling.

Better Sol lets you write Solana programs in TypeScript. One file defines your accounts and instructions. From that same file you deploy on-chain and get a typed client.

```tsx ts2js
// programs/counter.ts
import { bs } from "better-sol/program"

const Counter = bs.account({
  count: bs.u64(),
  authority: bs.pubkey(),
}).derive((seed) => ["counter", seed.authority])

export const counter = bs.program({ name: "counter", address: "<key>" }, ix => ({
  increment: ix({
    accounts: { counter: bs.mut(Counter), authority: bs.signer() },
    args: { amount: bs.u64() },
    run: ({ counter }, { amount }) => { counter.count += amount },
  }),
}))
```

Deploy:

```bash
npx @better-sol/cli@alpha deploy
```

Connect from your app:

```tsx ts2js
import { betterSol, keypairFile } from "better-sol"
import { counter } from "./programs/counter"

const sol = await betterSol({
  cluster: "devnet",
  payer: keypairFile("./keypair.json"),
  programs: { counter },
})
const addr = await sol.counter.accounts.Counter.derive({ authority: sol.payer })
await sol.counter.increment({ counter: addr, amount: 5n })
```

## Prerequisites

Node.js 22 or later.

## Install

```npm
npm install better-sol@alpha
```

The CLI runs via `npx`. No install needed. Add `@alpha` to get the latest prerelease.

## API key (optional)

Deploying compiles your program in the Better Sol cloud compiler. Because Better Sol is still experimental, compiler usage is rate limited: without an API key you get 20 compiles per hour, and with one you get 100 per hour.

Get a key from the [dashboard](/dash), then save it:

```bash
npx @better-sol/cli@alpha login <api-key>
```

It gets stored at `.better-sol/auth.json`.

## Agent Skill

Better Sol ships an [Agent Skill](https://agentskills.io): a single self-contained folder your AI agent can load to understand the full Better Sol SDK, Solana architecture, security patterns, and more. Works with Claude Code, Cursor, GitHub Copilot, Windsurf, Cline, and 40+ other clients.

```bash
npx skills add powxenv/better-sol@better-sol --yes
```

The skill includes 50 reference files covering programs, clients, testing, deployment, DeFi, NFTs, DAOs, security, frontend patterns, and web3 fundamentals. Your agent loads only what it needs for the task at hand.

See the [Agent Skill docs](/docs/agent-skill) for the full breakdown of what's included.
